## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Sync deletes files** | Use "Update" mode |
| **Diff too slow** | Filter large folders |
| **Merge conflicts** | Save before merge |
| **Encoding wrong** | Force UTF-8 |
| **Script fails** | Check path quotes |
| **Session lost** | Backup `.bcpkg` |
